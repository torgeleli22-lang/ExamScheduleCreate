# 시험 시간표 편성 도구

컴퓨터소프트웨어과 중간고사·기말고사 시간표를 짜기 위한 단일 HTML 도구입니다.
`index.html` 하나만 브라우저로 열면 동작합니다 (GitHub Pages로 배포).

## 학기마다 쓰는 법

1. 맨 위에서 **학년도 · 학기 · 시험(중간/기말)** 을 고릅니다. 아직 없는 시험이면 **자료 넣기** 화면이 나옵니다.
2. 그 학기 자료 파일을 **한꺼번에** 끌어다 놓습니다. 어떤 자료인지는 알아서 알아봅니다.
   - 학과 **강의시간표** (.xlsx)
   - **요일별 수업일 현황** (.pdf · .hwp · .xlsx, 또는 표 붙여넣기)
   - **보강결과보고서**(.hwp)·**보강 신청 목록**(.xls) 등 — 과목코드 끝자리나 분반(101=A, 102=B …)과 결강 요일·교시로 어느 반 수업인지 찾습니다.
   - 보강이 그 과목의 15주차(또는 8주차) 날짜보다 **뒤**에 잡혀 있으면 **시험이 그 보강 시간으로 밀립니다.** 밀린 과목은 날짜별 배치 위에 따로 보여 줍니다.
   - 같은 학기 중간고사 자료가 있으면 기말고사는 그대로 가져올 수 있습니다.
   - 시험 대상이 아닌 반(전공심화·야간 등)은 체크를 풀어 빼세요.
3. 확인 화면에서 시험 주차 날짜, **대체 수업일**(예: 12/15(화)에 금요일 수업), 보강 목록을 보고 **만들기**를 누릅니다.
4. **날짜별 배치**
   - **날짜 선택** 버튼을 누르면 달력이 열립니다. **8주차·15주차(시험 주차) 날짜는 다른 색**이고 칸에 "8주차", "15주차"가 적혀 있습니다.
   - 날짜를 **누르면 하나씩**, **끌면 연속으로** 고릅니다(Shift+누르기 = 이어서, 다시 누르면 빼기). "15주차 날짜 모두"로 한 번에 고를 수도 있습니다. **선택**을 누르면 적용됩니다.
   - 아래 **날짜별 시간표**에 고른 날짜가 **주마다 한 줄씩**, 줄 안에서는 **가로로** 나옵니다. 예: 11/18~11/23을 고르면 첫 줄에 11/18·19·20·21, 다음 줄에 11/23(11/22는 일요일).
   - 시험 블록을 다른 날짜·교시로 **끌어서** 옮깁니다(다른 줄로도). 끄는 중에 줄의 좌우 가장자리로 가면 자동으로 넘어갑니다. 블록마다 몇 주차 수업인지, 옮겼으면 원래 날짜가 적혀 있습니다.
   - 옮기지 않는 과목은 **'기존 시간표 수업 진행'** 으로 확정합니다(블록을 눌러 하나씩, 또는 위 버튼으로 한 번에).
5. 학기 중에 시간표·수업일·보강이 바뀌면 파일을 **화면 아무 곳에나 끌어다 놓으세요**(또는 **설정 → 자료 다시 넣기**). 종류를 알아보고 적용 버튼이 나옵니다. 백업 .json을 놓으면 백업 불러오기로 갑니다. 옮기지 않은 시험은 새 기본 시간을 따라갑니다.
6. 시험이 끝나면 **학기별 기록**에서 **보관(잠금)** 해 두세요. 언제든 다시 열어 볼 수 있고, 실수로 고쳐지지 않습니다.

## 할 수 있는 것

- **날짜별 배치**: 주차×요일 판에서 카드를 다른 날짜로, 펼친 반×교시 시간표에서 교시까지 옮깁니다.
- **시험 일정 등록**: 과목을 고르고 방식·날짜·교시·길이·강의실을 입력합니다. 등록 전에 겹침을 미리 보여 주고, 겹치지 않는 시간을 눌러 바로 채울 수 있어요.
- **시험 시간 직접 정하기**: 블록을 눌러 서랍에서 **시작 시간·종료 시간**을 넣을 수 있습니다(예: 13:40~15:10). 겹침·점심 경고는 **분 단위**로 검사하고(예: 12:05~13:00), 판의 블록도 그 시각만큼의 위치·크기로 그려집니다. 목록·엑셀에는 정한 시간이 나옵니다. **교시로 맞추기**로 교시 경계에 다시 맞출 수 있습니다.
- **강의실 고르기**: 강의실 칸을 누르면 가진 강의실이 모두 나오고, 그 시간에 **비어 있는 강의실**과 **사용 중인 강의실(어느 반 어느 과목)** 이 나뉘어 보입니다. 목록에 없으면 '직접 입력…'.
- **합반 시험**: 같은 과목의 다른 반 시험을 같은 날 같은 교시로 맞추면 합반 시험으로 보고 겹침으로 세지 않습니다('합반' 표시). 시작 교시가 다르게 걸치면 겹침입니다.
- **겹침 검사**: 같은 반 수업·시험·보강, 같은 교수님 일정, 같은 강의실을 그날 실제로 열리는 시간표(대체 수업일·보강·결강 반영) 기준으로 검사합니다.
- **과목 목록**: 표에서 방식·날짜·교시·강의실·메모·확정을 한 번에 수정.
- **다른 주차 수업 옮기기**: 8·15주차 수업은 바로 끌어서 옮길 수 있습니다. 그 밖의 주차 수업은 고정돼 있어서, **꾹 누르면(0.6초)** 점선 테두리와 '옮기기' 표시가 생기며 풀립니다. 누른 채로 끌어 옮기거나, 눌러서 날짜·시작/종료 시간·강의실을 고칩니다. 풀린 수업을 **다시 꾹 누르거나**, 상세의 **다시 고정하기**, 위쪽 **풀어 둔 수업 다시 고정** 버튼으로 다시 잠급니다. 옮긴 수업은 주황 테두리로 보이고 보강처럼 기록되어(설정 → 보강 목록, '직접 옮김') 겹침 검사·엑셀에 반영됩니다. **원래 자리로 되돌리기**를 누르면 기록이 지워집니다. 직접 옮긴 수업은 시험을 끌고 가지 않습니다(시험보다 뒤면 경고만).
- **엑셀 내보내기**: 학과 중간고사 시간표 양식 그대로 주마다 한 시트(①②③, 학년·반 × 날짜·교시, 학년별 색, 기존 수업 진행은 회색). 시험이 없어도 보강·옮긴 수업·옮긴 시험·메모 등 손댄 것이 있는 날은 '기존 수업 진행'으로 접지 않고 그날 수업을 교시별로 모두 보여 줍니다 / 과목별 목록 / 교수님별 시트.
- **학기별 기록**: 학기 × 중간/기말 시험을 모두 보관, 보관(잠금), 시험별·전체 백업(.json)과 불러오기.

## 저장: GitHub에 저장하기 (처음 한 번 설정)

페이지는 정적 페이지(GitHub Pages)이고, 데이터는 **이 저장소의 `data` 브랜치 `data/plans.json`** 에 저장됩니다.

1. GitHub에서 토큰을 만듭니다: 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: **Only select repositories** → 이 저장소만
   - Repository permissions → **Contents: Read and write**
2. 페이지의 **학기별 기록** 탭 → **GitHub에 저장** 칸에 토큰을 붙여 넣고 **연결하고 불러오기**.
3. 이후로는 고칠 때마다 몇 초 뒤 자동으로 커밋됩니다. 오른쪽 위에 "GitHub에 저장됨"이 보이면 저장된 것입니다.

- 다른 컴퓨터에서도 같은 주소를 열고 토큰을 한 번 넣으면 같은 데이터로 이어서 씁니다. 두 곳에서 동시에 고치면 시험별로 더 최근에 고친 쪽이 남습니다.
- 토큰이 없는 브라우저는 GitHub 데이터를 **보기만** 합니다(공개 저장소일 때). 거기서 고친 내용은 그 브라우저에만 남습니다.
- 토큰은 그 브라우저에만 저장됩니다. 공용 컴퓨터라면 다 쓴 뒤 **이 브라우저에서 토큰 지우기**를 누르세요.
- **저장소가 public이면 저장한 시험 일정과 메모도 누구나 볼 수 있습니다.** 비공개로 하려면 저장소를 private으로 바꾸세요(Pages를 쓰려면 GitHub Pro 필요, 학생은 Student Developer Pack으로 무료).
- 저장 기록은 GitHub의 `data` 브랜치 커밋 기록에 남아서, 예전 상태로 되돌릴 수 있습니다. **전체 백업 저장(.json)** 도 그대로 쓸 수 있어요.
- 엑셀 내보내기·파일 읽기는 처음 한 번 인터넷에서 ExcelJS / pdf.js를 불러옵니다.

## 개발

Node 20 이상.

```bash
npm install          # exceljs · pdfjs-dist · playwright (테스트용)
npm run build        # src/ + data/seed.json → index.html
npm test             # 단위 테스트(브라우저 없음) + 브라우저 종단 테스트
```

브라우저 테스트용 Chromium이 없으면 `npx playwright install chromium`을 한 번 실행하거나, `CHROME=/path/to/chrome npm test`처럼 경로를 지정하세요.

구조와 규칙은 [CLAUDE.md](CLAUDE.md)를 보세요.
