# 시험 시간표 편성 도구

컴퓨터소프트웨어과 중간고사·기말고사 시간표를 짜기 위한 단일 HTML 도구입니다.
`index.html` 하나만 브라우저로 열면 동작합니다 (GitHub Pages로 배포).

## 학기마다 쓰는 법

1. **학기별 기록** 탭(또는 위쪽 **+ 새 시험 만들기**)을 누릅니다.
2. 학년도·학기를 고르고 만들 시험(중간고사 8주차 / 기말고사 15주차)을 체크합니다.
3. 자료를 넣습니다.
   - **파일 올리기**: 학과 강의시간표 엑셀(.xlsx)과 **요일별 수업일 현황 PDF**. PDF를 못 읽으면 표를 복사해 붙여 넣어도 됩니다.
     시험 대상이 아닌 반(전공심화·야간 등)은 체크를 풀어 빼세요.
   - **다른 시험에서 가져오기**: 같은 학기 중간고사 때 올린 자료를 기말고사에 그대로 씁니다.
4. 미리보기에서 시험 주차 날짜와 **대체 수업일**(예: 12/15(화)에 금요일 수업)을 확인하고 **시험 만들기**를 누릅니다.
5. 각 과목의 시험 주차 수업 시간에 시험이 기본 배치됩니다. 교수님 요청이 있는 과목만 옮기세요.
6. 시험이 끝나면 **학기별 기록**에서 **보관(잠금)** 해 두세요. 언제든 다시 열어 볼 수 있고, 실수로 고쳐지지 않습니다.

## 할 수 있는 것

- **날짜별 배치**: 시험 블록을 끌어서 다른 날짜·시간으로 옮깁니다 (같은 반 줄 안에서).
- **시험 일정 등록**: 과목을 고르고 방식·날짜·교시·길이·강의실을 입력합니다. 등록 전에 겹침을 미리 보여 주고, 겹치지 않는 시간을 눌러 바로 채울 수 있어요.
- **겹침 검사**: 같은 반 수업·시험, 같은 교수님 일정, 같은 강의실을 그날 실제로 열리는 시간표 기준으로 검사합니다.
- **과목 목록 / 교수님 확인**: 표에서 한 번에 수정, 교수님별 확인 문구 복사.
- **엑셀 내보내기**: 학생 공지용 시간표 / 과목별 목록 / 교수님별 시트.
- **학기별 기록**: 학기 × 중간/기말 시험을 모두 보관, 보관(잠금), 시험별·전체 백업(.json)과 불러오기.

## 저장 (중요)

- 입력한 내용은 **이 브라우저에만** 자동 저장됩니다(localStorage). 다른 컴퓨터·브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 사라집니다.
- 그래서 학기가 끝나면 **학기별 기록 → 전체 백업 저장**으로 .json 파일을 받아 학과 공유 폴더에 보관하세요. 새 컴퓨터에서는 **백업 불러오기**로 이어서 씁니다.
- 엑셀 내보내기·파일 읽기는 처음 한 번 인터넷에서 ExcelJS / pdf.js를 불러옵니다.

## 개발

Node 20 이상.

```bash
npm install          # exceljs · pdfjs-dist · playwright (테스트용)
npm run build        # src/ + data/seed.json → index.html
npm test             # 단위 테스트(브라우저 없음) + 브라우저 종단 테스트
```

브라우저 테스트용 Chromium이 없으면 `npx playwright install chromium`을 한 번 실행하거나, `CHROME=/path/to/chrome npm test`처럼 경로를 지정하세요.

구조와 규칙은 [CLAUDE.md](CLAUDE.md)를 보세요.
