# 시험 시간표 편성 도구

컴퓨터소프트웨어과 2026학년도 2학기 기말고사 시간표를 짜기 위한 단일 HTML 도구입니다.
`index.html` 하나만 브라우저로 열면 동작합니다 (GitHub Pages로 배포 가능).

## 할 수 있는 것

- **날짜별 배치**: 각 과목의 15주차 수업 시간에 시험이 기본 배치됩니다. 시험 블록을 끌어서 다른 날짜·시간으로 옮길 수 있어요.
- **시험 일정 등록**: 과목을 고르고 방식·날짜·교시·길이·강의실을 입력해 등록합니다. 등록 전에 겹침을 미리 보여 주고, 겹치지 않는 시간을 눌러 바로 채울 수 있어요.
- **겹침 검사**: 같은 반 수업·시험, 같은 교수님 일정, 같은 강의실을 그날 실제로 열리는 시간표 기준으로 검사합니다.
- **과목 목록**: 표에서 방식·날짜·시간·강의실·요청사항·확정을 한 번에 수정합니다.
- **교수님 확인**: 교수님별 일정 확인 문구를 복사할 수 있어요.
- **엑셀 내보내기**: 학생 공지용 시간표 / 과목별 목록 / 교수님별 시트로 된 .xlsx 파일을 만듭니다.
- **설정**: 시험 주차(중간고사 8주차 등), 수업일 현황 붙여넣기, 새 학기 강의시간표(.xlsx) 불러오기, 백업(.json) 저장·불러오기.

## 저장

- 입력한 내용은 브라우저(localStorage)에 자동 저장됩니다. 다른 컴퓨터나 브라우저에서는 보이지 않으니 설정 탭의 **백업 파일 저장**을 이용하세요.
- 엑셀 내보내기는 처음 한 번 인터넷에서 ExcelJS를 불러옵니다.

## 개발

```bash
npm install                 # 테스트용 exceljs
python3 scripts/build.py    # src/template.html + data/seed.json → index.html
python3 tests/smoke_test.py # 헤드리스 Chrome 스모크 테스트 (playwright 필요)
```
